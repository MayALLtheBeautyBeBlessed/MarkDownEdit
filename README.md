# MarkEdit 6.6

一个安静的 Markdown 编辑器，Windows 原生窗口 + WebView2 内核，**Typora 式的即时渲染**：光标所在的段落显示原始 Markdown，其余段落直接显示排版结果。

双击 `MarkEdit.exe` 即可使用，**免安装、不联网、不加载任何远程资源**（公式的 KaTeX 也是本地内置的）。

---

## 一、四种视图

| 视图 | 快捷键 | 说明 |
| --- | --- | --- |
| **即时** | `Ctrl+1` | 默认。所见即所得，点哪块编辑哪块，移开光标即变回排版 |
| **双栏** | `Ctrl+2` | 左边源码 + 右边预览，中间分隔条可拖动 |
| **源码** | `Ctrl+3` | 纯 Markdown，带着色和行号 |
| **阅读** | `Ctrl+4` | 只看渲染结果，适合通读校对 |

即时渲染里的行为：

- 点击任意段落 → 该段变成原始 Markdown，字号/缩进/边框仍保留该段落的排版特征
- 光标移开（点击别处、按 Tab、切换视图）→ 立刻变回渲染结果
- `Enter` 拆段：在列表里自动续 `-` / 递增的 `1.`，空列表项再回车就退出列表
- `Backspace` 在段首：并到上一段；`↑` `↓` 在段首段尾：跨段移动
- `Ctrl+B / I / K / E`：给选区加标记
- `Ctrl+Z` / `Ctrl+Shift+Z`：块级操作的撤销重做

## 二、1.6 新增（这一版动的是内核）

### 1. 编辑时就是渲染态

以前的「即时渲染」其实是**先变成源码、失焦再渲染**：点一段会把 `#`、`**` 露出来。现在整个编辑器改成了**渲染态直接编辑**：

- 块的 DOM 就是排版结果，你敲字直接敲在渲染好的内容里
- 输入 `**加粗**`、`*斜体*`、`` `代码` ``、`~~删除~~`、`==高亮==`，**收尾符号一敲完就当场变成格式**，不会看到一堆星号
- 行首输入 `# `、`- `、`1. `、`> `、```` ``` ```` 会立刻变成标题 / 列表 / 引用 / 代码块
- Markdown 源码由 DOM **反向序列化**得到，保存下来的仍是标准 Markdown
- `Ctrl+B / I` 这类快捷键直接作用在渲染内容上（是加粗，不是插入星号）
- 表格仍是点单元格编辑；公式块点一下变成 TeX，失焦再渲染

代价：块内的“标记符号”平时是隐藏的，想手改 `#` 建议按 `Ctrl+/` 切源码模式。

### 2. 菜单栏（照着 Typora 做的）

顶栏换成了 **文件 / 编辑 / 段落 / 格式 / 视图 / 主题 / 帮助** 七个菜单，每一项都带快捷键提示，悬停切换、点外面或 `Esc` 关闭。

原来的图标工具条去掉了，排版命令都在「段落」「格式」里，右侧保留视图切换、全屏、主题、设置、快捷键五个按钮。

**1.6.1 修正**：开启背景图后，最上面的菜单栏、标签栏也会跟着透明（之前是实心面板挡住了）。下拉菜单本身仍然不透明，保证文字可读。

**1.6.2 修正**：背景图模式下，下拉菜单会被侧栏/标签栏压住 —— 原因是菜单栏上的 `backdrop-filter` 生成了层叠上下文，把菜单的 `z-index` 困在了里面。给菜单栏加 `position: relative; z-index: 40` 后恢复正常。

**1.7 新增 / 修正**

- **侧栏不再强制磨砂**：之前侧栏写死了 `blur(10px)`，跟「毛玻璃」开关无关；现在和菜单栏完全一致 —— 默认 `blur(0)`，纯透明直接看背景，想磨砂才开开关。
- **侧栏宽度可拖拽**：把鼠标放到侧栏右边缘（会出现一条高亮竖线），拖动即可改宽度，范围 180–560px；**双击边缘恢复 262px**；宽度会记进 `data\prefs.json`，下次打开保持。

**1.8 新增**

- 欢迎页底部那行快捷键提示去掉了
- 设置里新增「数据」一节，直接显示**配置与数据目录**，还能一键打开；如果程序跑在临时目录（典型情况：直接双击压缩包里的 exe），这里会红字提示「设置不会被保留」
- 撤销上限从 60 提到 **200 步**

**1.9 新增**

- **窗口 / 任务栏图标**改成蓝底白 M（之前标题栏是 .NET 的默认图标，因为没显式设置 `Form.Icon`）
- **注册到「打开方式」**：启动时自动写一次注册表（`HKCU\Software\Classes`，不需要管理员），之后右键任意 `.md` → 打开方式里就能看到 MarkEdit；菜单「文件 → 注册到「打开方式」」可以手动重注册（搬动文件夹后点一下即可刷新路径）。想设为默认：右键 → 打开方式 → 选择其他应用 → MarkEdit → 勾选「始终使用」。

**1.9.1 修正**

- **自动保存默认改成 180 秒**（原来是 5 秒）；设置里仍可 1–600 秒自定义，存进 `prefs.json` 后一直生效
- **图片三处修复**
  - 插入后**立刻显示**：之前插的是相对路径 `assets/x.png`，在那个位置解析不到，要等一次整篇重渲染才出现（就是你看到的十几秒）
  - **任意位置都能选中缩放**：以前只有「独占一段的图片」才有拖拽手柄，段落里的行内图片点不出手柄；现在只要点到图片就能拖
  - **可选、可删**：点图片出现选框后，按 `Delete` / `Backspace` 直接删除，`Esc` 取消选中
- 存盘仍写相对路径 `![](assets/xxx.png)`，不会写成绝对路径（DOM 里用 `data-src` 记住原路径）

**2.0 新增 / 修正**

- **右键菜单加「插入」子菜单**：表格、图片、代码块、公式块、引用、三种列表、分割线，都带快捷键提示；菜单靠近右边缘时子菜单自动往左展开
- 去掉选中图片时下方那行「拖动右下角改变宽度」的小字（手柄和边框还在）
- **列表序号现在能用 Backspace 去掉**：光标在列表项开头按 Backspace，这一项会从列表里摘出来变成普通段落（前后的项仍是列表）
- 顺带修掉一个更底层的老 bug：`caretAtStart` / 光标列号的计算方向反了（取的是"光标之后"的文本），导致"行首 Backspace"实际只在行尾生效，可能把上一段误合并
- 图片路径归一化：序列化时会把 `file:///`、绝对路径转回文档相对路径（`assets/xxx.png`），避免把本机路径写进 md

**2.1 新增 / 修正**

- **表格、图片、分割线、公式块、代码块后面总会有一个可写空行**：插到文档末尾时自动补一个空段落，不会再出现「表格下面点不进去」的死角
- **删块**：光标放在这类块的下一行开头（或空行里）按 `Backspace`，直接删掉上面那个块；表格在文档中间也能这么删
- **上下方向键可以跨块移动**：光标在块尾按 `↓` 跳到下一块开头，在块首按 `↑` 跳到上一块末尾；遇到表格/分割线这类不可直接编辑的块会自动跳过
- **新建空白文件**：`Ctrl+Alt+N` 或「文件 → 新建空白文件…」，直接弹保存对话框、落盘一个空 `.md` 再打开；原来的 `Ctrl+N` 保留为「新建标签页」（不落盘）

**2.2 新增 · 表格内的键盘操作**

点进任意单元格后：

| 按键 | 作用 |
| --- | --- |
| `Tab` / `Shift+Tab` | 下一格 / 上一格（到末尾自动加一行） |
| `↑` / `↓` | 同列上一行 / 下一行 |
| `←` / `→` | 光标在单元格文字两端时跳到相邻格 |
| 首行按 `↑`、首格按 `←` | 结束编辑，跳到表格**上面**的段落 |
| 末行按 `↓`、末格按 `→` | 结束编辑，跳到表格**下面**的段落 |
| `Enter` | **在下面加一行**，光标落到新行 |
| `Shift+Enter` | **单元格内换行**（存成 `<br>`，重新打开仍是两行） |
| `Esc` | 结束编辑 |
| 右键单元格 | 上方/下方插入行、左/右插入列、上移/下移行、左移/右移列、删除行/列、复制表格、删除表格 |
| 点击表格外面 | 自动结束编辑 |

表格下面的落点就是自动补的那个空段落，可以直接继续写。

**2.4 修正**

- **Ctrl+Z 不再丢光标**：撤销 / 重做会记住「哪个块 + 块内偏移」，恢复后光标回到原处，不用再点鼠标
- **右键「插入」菜单可用**：以前从菜单发起的命令拿不到选区就静默失败；现在没有选区时回落到最近编辑过的块
- **代码块能删**：光标在代码块开头按 `Backspace`，有内容就**去掉代码块外壳变成普通段落**，空的直接删掉
- **表格行列操作重写**：改为记住「当前单元格」而不是靠 `document.activeElement`（点菜单时焦点已经跑到按钮上，所以之前加行加列位置乱、删行无效）
- 表格右键菜单补齐成 Typora 那套 13 项

**2.5 新增 / 修正**

- **表格浮动工具条**：点进单元格，表格上方会浮出一排图标 —— 整列左/中/右对齐、上方插入行、下方插入行、左侧插入列、右侧插入列、删除行、删除列、删除表格；靠视口顶部时会自动翻到表格下方
- **撤销后光标回到改动处**：快照现在会连同「改动发生时的光标位置」一起存，撤销时光标跳回那次编辑的位置，而不是停在你看别处时的位置
- **文末插图后能继续写**：在文档最后插图片会自动补一个空段落（以前图片顶到文末就再也点不进去了）

**2.6 修正**

- **撤销后的光标位置重做**：快照现在记的是「改动发生时的光标」，撤销一次 → 回到上一次改动处，再撤销 → 回到再上一次，逐级往回走（实测 0 → 7 → 5）
- **表格内 `Ctrl+A`**：选中所有单元格内容（整个表格），不再是只选当前格
- **表格内点击定位**：第一次点进单元格不再强行把光标扔到末尾，交给浏览器按点击位置放；已在编辑时点哪儿就在哪儿
- **图片下面必定可写**：打开文档时如果最后一段里含图片，也会自动补一个空段落，老文档同样生效

**2.7 修正**

- **点击空白处就能落光标**：点段落之间的空隙、图片/表格下方的空白、文末的空白区，光标会落到**被点的那个块**（点在下半部分→行尾，上半部分→行首；点在最后面→全文末尾），不用再找那行空白在哪
- **撤销光标**：撤销后光标停在**恢复出来的那段文字之后**（`1234` 删成 `12` 再撤销 → 光标在 `1234` 末尾，直接接着打字就是 `1234X`）
- **方向键进出表格**：段尾按 `↓` 直接进表格第一个单元格；表格末行按 `↓` 回到下面段落；下面段首按 `↑` 回到表格

**2.8 修正**

- **表格 / 图片 / 分割线 / 公式块后面固定垫一个空段落**：打开任意 md 时都会自动生成（只存在于编辑器里，存盘时跳过，不会往文件里加空行）。这样表格下方永远有落脚点，`↓` 出表格直接落到这一行
- **撤销变快**：以前要等 0.7 秒的防抖快照才生效，现在按 `Ctrl+Z` 会先把还没入栈的改动同步入栈再撤销，按下去立刻有反应

**2.9 修正（关键）**

- **回车时格式跟着文字走**：这才是「表格下面那个标题点了回车格式就没了」的真正原因 —— 以前回车拆分时**后半段一律变成普通段落**，所以在标题开头/中间回车，文字就被降级了。现在：
  - 标题中间回车 → 两半**都是标题**
  - 标题开头回车 → 上面多一个空段落，文字**仍是标题**
  - 标题末尾回车 → 新行是**普通段落**（不会一直写标题）
  - 引用 / 列表同理
- 引用块序列化会去掉首尾多余空行，不再写出 `> ` 空行
- 撤销了 2.8 的「每个表格/图片后面都强插空段落」——那个是治标，现在不需要了；文末仍保留补空行

**2.9.1 修正**

- **Backspace 不再偷偷把标题降级**：以前光标在标题开头按 Backspace，标题会被就地改成普通段落（文字不动、格式没了）。现在的规则：

按 Typora 的两段式来（`2.9.3` 起）：

- 上一块是空行 → 只删掉空行，当前块格式不动
- 上一块是表格 / 图片 / 代码块等 → 删掉那个块
- **段落 + 段落** → 直接合并成一段（不插空行）
- **标题 / 引用在段落下面** → 第一次 `Backspace` 取消格式（变成普通段落），**再按一次**才与上一段合并

**3.0 修正 · 代码块和公式块点不进去**

两个都是 2.7 加的「点空白处落光标」误伤：

- 点公式块时，那一层 `div` 不是可编辑元素，被当成“空白”，直接走了落光标分支，**永远进不了 TeX 编辑**
- 代码块点边框/头部时同理；更糟的是**在代码块里打字会把围栏弄丢**（序列化用的是 `<code>` 而不是 `<pre>`），打一个字代码块就变成普通段落了 —— 所以看起来像“根本不能编辑”

现在 `mousedown` 按「图片 → 表格单元格 → 公式块 → 代码块 → 可编辑内容 → 空白」的顺序分发，并且代码块序列化固定用 `<pre>`。

**3.1 新增 · 关闭前确认**

点窗口 ✕ / Alt+F4 时，如果有未保存的修改，会弹一个小窗：

- **保存并关闭** —— 有路径就直接写盘再退；没路径则弹另存为，取消就不退
- **不保存** —— 直接退出
- **取消** —— 留在编辑器（`Esc` 同效，`Enter` 等同保存）

没有改动时不会打扰，直接关。有多个标签页时，提示里会说明当前保存的是哪一个。

**3.2 换图标**

- 应用图标：**白卡片 + 衬线 M + 稿纸横线**（仿 Typora 那种卡片感，4 倍超采样，16～256 多尺寸）
- 欢迎页顶部的标记同步换成同一个样式

**3.5 新增 · 调字体时能看见效果**

- 设置面板顶部加了**实时预览**：标题 / 正文 / 加粗斜体行内代码 / 引用，跟着字体、字号、行高、行宽、正文颜色**即时变化**
- 设置窗口可以**按住标题栏拖动**（双击标题回到居中），拖到一边就能对照后面的正文
- 遮罩从 38% 降到 22%、模糊从 2px 降到 1px，背后的文档看得更清楚（正文本身也是实时应用的）

**3.6 修正 · 跨行选中**

- **鼠标可以跨段拖选了**：每个块是独立的 `contenteditable`，浏览器的原生拖选到块边界就停；现在拖到别的块时会用 `Selection.extend()` 手动接上（优先按指针位置精确落点，拿不到就落到整块的起/止）
- 跨块选区**复制可用**：实测选中两个段落按 Ctrl+C，剪贴板拿到完整的 107 个字符
- **`Ctrl+A` 全选整篇**（之前只选当前块）；在表格里 `Ctrl+A` 仍然是选整张表

**3.7 修正 · 选区看得见了**

- 真正的根因：**Chrome 不会给「跨编辑域」的选区上色**。选区对象是存在的（`Range` 里 1000 多个字符），但屏幕上一片空白，看起来就像"没选中"
- 现在自己画：`selectionchange` 时算出选区覆盖了哪些块，给这些块加 `.in-sel` 高亮，块内的文字仍由浏览器原生高亮
- 顺带：多块选区下按 `Delete` / `Backspace` 会**整段删除**（之前浏览器只在当前编辑域里删，跨块部分删不掉），删完自动留一个空段落、光标落回去

**3.8 修正 · 选区重做**

- **不再用块底色**，改成按字符精确绘制的叠加层：取 `Range.getClientRects()`，每个行盒画一个矩形，跟文字严丝合缝；同时把原生 `::selection` 设为透明，**不会再出现两层颜色叠在一起**
- **拖选精确到字**：落点依次尝试 `caretRangeFromPoint` → `caretPositionFromPoint` → 「找纵向最近的一行 + 按横坐标二分」，不再是整块整块跳
- **表格里也能起选、拖出去**：在单元格里按下就记锚点，拖到表格外照样接上
- **块边距上按下也能起选**（以前点在段落左右留白里不会起选，这就是"从下往上偶尔拖不动"的原因）
- **拖到上下边缘自动滚动**，长文档里可以一路拖着走

**3.9 修正 · 像 Typora 那样只高亮文字**

- 高亮不再画"整块矩形"，改成**逐文本节点切片**：只给真正有字的部分上色，行尾、左侧留白、列表符号都不再被涂满 —— 看起来就是 Typora 那种"只选字"
- 拖选的落点**直接采用指针的真实位置**（原来会被强行吸附到目标块的开头/结尾，所以像"一块一块跳"）；只有拿不到时才回退到块
- 实测：从第 6 块往上拖到第 3 块，选中 92 字符、画出 20 个文字级高亮片 ✓

**4.0 内核重写（重要）**

把编辑器从「每个段落一个 contenteditable」改成 **整篇只有一个 contenteditable**（块只是里面的 `<p>/<h1>/<ul>`），和 Typora 的模型一致。因此：

- **选区是浏览器原生的**：跨段拖选、从下往上、从表格里拖出去、`Ctrl+A`、`Shift+点击` 全部由浏览器负责，颜色和手感跟系统一致 —— 之前自绘叠加层、块级吸附那一整套补丁都删掉了
- **方向键原生跨段**，不用再手工跳块
- **撤销是浏览器原生的**（每个编辑动作独立入栈，比之前的快照更细）
- 表格里 `Tab` 跳格、`Enter` 加行、`Shift+Enter` 换行；表格浮动工具条保留
- 旧内核保留在 `web/wysiwyg.legacy.js`，需要时改一行 script 就能切回

代价：第一次保存会把文件**规范化**（换行统一为 LF、连续空行压成一个），内容语义不变。

**5.0 性能：连续撤销不卡**

撤销本身已经对了，慢在“每撤一步都重算全篇”。三处优化：

1. **块列表缓存**：`blocks` 只在 DOM 真的变化时重算（原来每次 `selectionchange` 都全篇序列化一遍）
2. **通知延到下一帧**：撤销后把 `onChange` 放进 `requestAnimationFrame`，连按 Ctrl+Z 时多步只触发一次大纲/字数刷新
3. **只序列化一次**：每步撤销只调一次 `getContent()`

实测：12,685 字的文档，**每步撤销 0.73 ms**（原来包含两次全篇序列化 + 每次 selectionchange 的重复计算）。

**5.1 撤销再提速**（对照 Typora 的做法）

Typora 用的是 CodeMirror 6：文档是一棵不可变的状态树，每次编辑产生一个 **transaction**（只记录改动的区间），撤销就是把 transaction 反向应用，视图只重绘改动的那几行 —— 所以再大的文档也是 O(改动量)。

我们的快照式撤销做不到那么细，但可以把「整篇重建」压成「只换变化的块」：

- `applyHtml()`：把快照 HTML 解析出来，**逐个顶层块比对 `outerHTML`，只替换不同的那几个**（撤销通常只影响一个段落）
- 撤销期间挂起 `selectionchange` 里的重复计算

**5.2 换成 CM6 式「差异事务」**

不再保存整篇 HTML 快照，而是每次改动只记一条**事务**：

```
{ start, removed[], added[], caretBefore, caretAfter }
```

- 改动发生时，把顶层块列表做「公共前缀 + 公共后缀」比对，只保留变化的那几块（打字通常只有 1 块）
- 撤销 = 反向应用事务：删掉 `added`、插回 `removed`，**只动那几个节点**
- 重做 = 正向应用

这跟 CodeMirror 6 的 `changeset` 是同一个思路（它是字符级、我们是块级），撤销的开销从「整篇重建」降到「改动的块」。

实测（含强制重排）：

```
29,786 字文档：每步 0.92 ms   （5.1 是 3.33 ms，5.0 之前更多）
```

**5.3 修正（严重）**

渲染器给表格套了 `<div class="table-wrap">`，而编辑器把顶层子元素当块，于是**表格根本不是顶层块**：

- 序列化时被跳过 → **保存会把整个表格丢掉**（4.0 起就有，一直没被发现）
- 表格在 DOM 里属于那个 div，删表后的差异事务边界落在 div 上，撤销时容易只恢复了 div 的一部分 → 表现为"删表后立刻撤销失败"

修法：`toEditHTML` 里把 `.table-wrap` 拆掉，表格直接作为顶层块。

实测：样例文档的表格 6 行，删除 → 撤销，DOM 恢复 1 张表、Markdown 恢复 6 行 ✓

**5.4 修正：删表后立刻 Ctrl+Z**

`onKeyDown` 第一行是 `const blk = this.currentBlock(); if (!blk) return;`，而撤销分支排在这个判断**后面**。删表后选区随表格一起被移除，`currentBlock()` 取不到块 → 整个按键处理直接 return → `Ctrl+Z` 根本没到撤销逻辑（所以要先点一下别处、让选区恢复才灵）。

实测：

```
输入「我觉得你还是不能直接识别出裸链接https://www.4399.com」
→ 320ms 后变成 裸链接<a href="https://www.4399.com">…</a> ✓
→ 光标仍在行尾 ✓
→ 源码 www.4399.com 也补成了 https:// ✓
```

**6.5 修正：链接被切成两半**

6.4 的"停手 320ms 就整理"有个副作用：如果你**打到一半停了一下**（比如 `https://www.4399`），它就把这半截变成链接了，接着再打 `.com` 就落在了链接外面 —— 结果是一个断成两截的链接。

现在：

- **光标所在的 URL 一律不动**（说明你还在敲）
- 光标离开这段 URL（继续打字到它后面 / 按回车 / 点别处失焦）才收网，**整条 URL 一次性变成链接**
- 同时处理当前块和上一次编辑的块，所以按回车换段之后上一段也会补上

实测：

```
打到 https://www.4399（光标在末尾）→ 不动 ✓
继续打 .com                        → 仍不动（光标还在 URL 里）✓
光标移到后面（敲空格+字）           → 整条变链接 ✓
光标在别处、行尾是完整 URL          → 变链接 ✓
```

**6.6 修正：敲完直接回车不识别**

6.5 的规则是"光标还在 URL 里就先不动"，但**按回车时**光标正好在 URL 末尾，于是被判成"还在敲"，结果换段之后这个块就再也没机会了（`_lastBlock` 已经指向新段）。

现在给三个时机加了**强制整理**（忽略"光标在 URL 里"这条）：

- **按回车**：分段之前先把当前段的链接定下来
- **失焦**（点别处）：强制整理上一次编辑的块
- 打字过程中的 320ms 定时整理仍然遵守"光标在 URL 里就不动"，所以不会切段

实测：

```
敲完 https://www.baidu.com 直接回车 → 段内已变成链接 ✓
源码：第一段[https://www.baidu.com](https://www.baidu.com) ✓
```：标题「愿我如星君如月」，正文含加粗、斜体、行内代码，下面一句引用「最是人间留不住，朱颜辞镜花辞树」

## 三、1.5 新增

### 1. 全屏无边框（这次真的生效）

之前 F11 会被 WebView2 当浏览器加速键吞掉，所以窗口边框根本没变。现在改成在**消息泵层面**拦截 F11（`IMessageFilter`），并且：

- 去掉窗口边框 + 铺满整块屏幕 + **置顶**，连任务栏一起盖住
- 顶栏多了一个 ⛶ 按钮，不想按键盘也能进全屏
- `Esc` 或再按 `F11` / 点 ⛶ 退出，回到原来的位置和大小
- 设置里可以关掉「全屏时隐藏窗口边框」，关掉就是普通最大化

### 2. 侧栏 / 顶栏纯透明（磨砂可选）

背景图现在会透过左侧目录、工具条、标签栏、状态栏。默认是**纯透明，不加磨砂**；想要毛玻璃就在设置里打开「毛玻璃效果（磨砂）」，用的是 10px 的 `backdrop-filter`。

配合「侧栏 / 工具栏不透明度」滑块（0–100%），20% 左右就是整窗浮在图片上的效果，100% 回到纯色面板。

### 3. 自动保存间隔改成手填

不再是滑条，直接输入数字（1–600 秒），回车或失焦生效，默认 **5 秒**（原来是 1.4 秒，确实太勤）。

### 4. 字体颜色自定义

设置 → 正文颜色：

- 点色块打开取色盘，选完立即生效
- 也可以直接在输入框里填 `#RGB` / `#RRGGBB`，回车生效
- 次要文字（大纲、状态栏）会按比例自动调和，保持层次
- 「跟随主题」一键还原

## 八、常见问题

**设置为什么每次打开都要重来？**
所有设置都存在 `<程序目录>\data\prefs.json`。如果程序目录是只读的，会退到 `%LOCALAPPDATA%\MarkEdit`。但如果**直接在压缩包里双击 exe**，Windows 会把它解到临时目录运行，设置自然一次性——设置里「数据目录」那一栏能直接看到实际路径，路径在 `Temp` 下就是这个问题。解压到固定文件夹再用即可。

**撤销能退多少步？**
**200 步**（`Ctrl+Z`）。步数按「编辑动作」算：连续打字会在停顿约 0.7 秒后合并成一步，回车拆段、改标题级别、插入表格这类结构性操作各算一步。

## 九、边界

- 即时渲染是**按块**的：一个块内仍是纯文本，但块的排版特征保留。
- 图片缩放只对**独立成段**的图片生效。
- 表格单元格里写 `|` 会被转义，不支持单元格内换行。
- 数学公式在 Word 里是 TeX 文本；PDF / HTML 导出是渲染好的公式。
- 背景图是整窗固定图层，不随文档滚动。
