# Lanyu 6.6

Typora 风格的 Windows Markdown 编辑器。单文件、离线，解压即用（需要 WebView2 运行时，Win10/11 自带）。

## 下载

- **Lanyu-6.6-win64.zip**（768 KB）— 解压后运行 `Lanyu.exe`

首次运行会在 exe 同级目录建 `data\` 存配置。**不要把 exe 单独拖出文件夹**，也不要在压缩包里直接双击（那样配置会写到临时目录，关掉就没了）。

## 这一版有什么

**编辑内核**
- 整篇文档只有一个编辑域，选区和 `Ctrl+A`、方向键、`Shift+点击` 都是浏览器原生行为
- 撤销是差异事务式的：只记录变化的块，29k 字文档每步 0.9 ms
- 首次保存会把文件规范化（换行统一 LF、连续空行压成一个）

**块元素**
- 表格：插入时可选行列、空表正常行高、浮动工具条、列宽拖拽（写回分隔行的短横线数量）、`Tab` 跳格、`Enter` 加行、上下键跨行
- 公式块：Typora 式编辑态（带边框的源码区 + 实时预览 + 右上角 ✓）
- 代码块：语法高亮、右下角语言角标（26 种语言可选）
- 图片：点选、拖拽改宽、`Delete` 删除
- 脚注（可点跳转）、内容目录（可点跳转）、YAML Front Matter

**输入体验**
- `# `、`- `、`1. `、`> `、```` ``` ```` 自动成块
- `**粗体**`、`*斜体*`、`` `代码` ``、`~~删除~~`、`==高亮==` 边打边成格式
- 裸链接识别：`https://`、`www.` 均可，紧贴中文也行；点链接交给系统浏览器
- 插入菜单对齐 Typora：图像 / 脚注 / 链接引用 / 水平分割线 / 表格 / 代码块 / 公式块 / 内容目录 / YAML Front Matter / 段落（上/下）

**其他**
- 三种视图：即时 / 双栏 / 源码 / 阅读
- 大纲、文件夹树、字数统计、自动保存（默认 180 秒）
- 关闭前有未保存提示
- 文件关联：启动时自动注册，`.md` 默认图标是我们的（可在菜单里强制设为默认）

## 已知限制

- 单文件建议 50 万字以内；150 万字开始打字有迟滞（瓶颈是浏览器对超大 DOM 的编辑布局），300 万字仍能打开和保存
- 脚注 / 链接引用目前是标记渲染，没有做引用跳转
- 书目模式（一章一个文件、全书统计）还没做

## 校验

- `src/MainForm.cs`、`src/DocxExport.cs` 用 Roslyn 编译，目标 .NET Framework 4.x + WebView2
- 依赖 KaTeX 0.16（已内置在 `web/vendor`，完全离线）

完整改动记录见 [README.md](https://github.com/MayALLtheBeautyBeBlessed/MarkDownEdit/blob/main/README.md)。
